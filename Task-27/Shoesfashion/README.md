A modern shoe shopping cart application built using React and Vite. This project allows users to browse different shoes, add products to the cart, increase or decrease quantities, and view the total cart price dynamically.

The application focuses on React fundamentals such as components, props, state management, event handling, conditional rendering, and dynamic UI updates.


## Features
  -> Display multiple shoe products with images and pricing
  -> Add products to the shopping cart
  -> Increase and decrease product quantity
 ->Remove item automatically when quantity becomes 0
 ->Dynamic cart total calculation
 ->Reusable React components
 ->Responsive layout design
 ->Fast development setup using Vite

 ## Tech Stack
React.js
JavaScript (ES6)
CSS3
Vite

## Tools & Packages
React Hooks (useState)


## Installation & Setup
  1. Clone the Repository
     git clone <your-repository-url>
  2. Navigate to Project Folder
    cd Shoesfashion
  3. Install Dependencies
    npm install
  4. Start Development Server
    npm run dev
